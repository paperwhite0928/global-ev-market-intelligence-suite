## 📌 1. Project Background & Executive Thesis

### 🔍 The Core Problem: Why Did Germany Suffer the 2022 Energy Shock?
Following the Russia-Ukraine war, Germany faced severe industrial inflation because strategic planning failed to hedge against the abrupt cutoff of cheap Russian natural gas. **The exact same systemic vulnerability is now threatening the German automotive powerhouse.**

### 🎯 The Objective: Pre-emptive Risk Hedging in an 83.5M Zero-Sum Market
Between 2026 and 2035, the global automotive market will remain locked in an **83.5M ~ 90M unit zero-sum stagnation** due to vehicle affordability friction and fleet aging (expanding to an all-time high of **12.5 years**). In this unforgiving environment:
- **China Profit Collapse**: Legacy European OEMs can no longer rely on Chinese joint venture dividends (historically 40% of group EBIT).
- **Regulatory Whiplash**: The EU 2035 ICE ban faces an 85% probability of revision/delay, while Western protectionism erects 100% tariff walls.
- **Supply Chain Decoupling**: Domesticating critical battery minerals from non-China sources introduces a structural **+$25/kWh to +$35/kWh cost penalty**.

This project delivers an **Interactive Geopolitical Simulation Engine & Dynamic OEM Playbook** to pre-emptively stress-test OEM portfolios and execute decisive Business Continuity Planning (BCP).

## 🎛️ 3. Geopolitical Simulation Engine (4 Exogenous Variables)

The dashboard dynamically recalculates market shares, battery costs, and corporate playbooks in real-time across 4 exogenous parameters:

1. **🇪🇺 EU 2035 Mandate Delay Intensity (0~100%)**: Expands legal recognition for 100km+ Gen-2 PHEVs, EREVs, and carbon-neutral synthetic e-Fuels.
2. **🇺🇸 Western Tariffs & Connected Car Embargo (0~100%)**: Escalates trade friction, Section 301 tariffs, and cybersecurity supply chain restrictions.
3. **⛏️ Non-China Arctic/Greenland Mineral Premium ($0~$50/kWh)**: Captures cell cost inflation from domesticating raw material supply chains.
4. **⚡ AI Grid Crisis & V2G Mandate Ratio (0~100%)**: Quantifies power grid stability regulations requiring mandatory bi-directional vehicle-to-grid (V2G) inverters and energy monetization.

## 💻 5. Step-by-Step Installation & Execution Guide

Follow these instructions to run the interactive dashboard locally:

### ⚙️ Prerequisites
- **Python 3.9+** installed on your system.
- Terminal / PowerShell / Command Prompt access.

### 🚀 Quick Start Instructions

```powershell
# 1. Navigate to the project root directory
cd 04-mobility-geopolitical-bcp-engine

# 2. (Optional but Recommended) Create and activate a virtual environment
python -m venv venv
# On Windows PowerShell:
.\venv\Scripts\Activate.ps1
# On macOS/Linux:
# source venv/bin/activate

# 3. Install required Python dependencies
pip install -r requirements.txt

# 4. Launch the Streamlit Interactive BCP Dashboard on Port 8503
streamlit run app.py --server.port 8503
```

### 🌐 Accessing the Application
Once the command is executed, your default web browser will automatically launch:
- **Local URL**: `http://localhost:8503`
